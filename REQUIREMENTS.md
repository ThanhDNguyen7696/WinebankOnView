# WineBank Website Requirements

## Project Information

**Project Name:** WineBank -- Premium Wine E-commerce Website

**Author:** Lucas Nguyen

**Purpose:**\
This project is a responsive front-end e-commerce website developed as a
university showcase project. It demonstrates a modern wine retail
website with product browsing, shopping cart functionality, membership
information, events, and contact features.

------------------------------------------------------------------------

# Functional Requirements

## Home Page

-   Display a responsive landing page.
-   Display hero banner.
-   Display featured wines.
-   Display a wine catalogue.
-   Allow users to search wines.
-   Allow users to filter wines by category.

## Shopping Cart

-   Add products to cart.
-   Remove products from cart.
-   Update product quantity.
-   Calculate total price.
-   Store cart data using Local Storage.

## Membership

-   Display membership information.
-   Display membership benefits.

## Events

-   Display upcoming wine tasting events.

## Contact

-   Display contact information.
-   Display an embedded Google Map.
-   Allow users to submit an enquiry form.

## User Account

-   Login page.
-   Registration page.
-   Client-side validation.
-   Demo member dashboard.

------------------------------------------------------------------------

# Non-functional Requirements

-   Responsive design.
-   User-friendly interface.
-   Cross-browser compatibility.
-   Fast loading performance.
-   Maintainable source code.

# Software Requirements

-   Visual Studio Code
-   Live Server Extension
-   Google Chrome (Recommended)

------------------------------------------------------------------------

# Technologies Used

-   HTML5
-   CSS3
-   JavaScript (ES6)
-   Local Storage API
-   Google Maps Embed

------------------------------------------------------------------------

# Installation

1.  Open the project folder in Visual Studio Code.
2.  Install the Live Server extension.
3.  Right-click **index.html**.
4.  Select **Open with Live Server**.

------------------------------------------------------------------------

# Limitations

-   Educational project only.
-   No real payment processing.
-   Cart data is stored in Local Storage only.
